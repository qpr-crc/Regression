# Regression

Решение задачи регрессии на наборе данных Mercedes-Benz Greener Manufacturing. Модель прогнозирует время тестирования автомобиля по его конфигурационным признакам.

## Проекты

- `Regression.Core` — модели данных, подготовка признаков и pipeline LightGBM.
- `Regression.CLI` — загрузка CSV, пятифолдовая кросс-валидация, обучение, прогнозирование и создание `submission.csv`.
- `Regression.ModelBuilder` — отдельный эксперимент с Model Builder и автоматически подобранной моделью FastTree.

Категориальные признаки преобразуются с помощью one-hot encoding, после чего объединяются с числовыми признаками в общий вектор `Features`.

## Запуск

Требуется .NET 10 SDK.

```powershell
dotnet run --project Regression.CLI
dotnet run --project Regression.ModelBuilder
```

По умолчанию проекты используют CSV-файлы из собственных каталогов `Data`. Для `Regression.CLI` также можно передать пути к обучающему файлу, тестовому файлу и файлу результата через аргументы командной строки.

## Результаты

| Вариант | MAE | RMSE | R² |
|---|---:|---:|---:|
| LightGBM, стандартные параметры | 5,683 | 8,716 | 0,528 |
| Model Builder, FastTree | 5,176 | 8,342 | 0,567 |

Метрики получены методом пятифолдовой кросс-валидации на обучающей выборке.
